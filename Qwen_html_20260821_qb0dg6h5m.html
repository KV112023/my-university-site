使用教程

1. 本站所有初始数据默认空白，不会替你随便填入。

2. 「消费额度」：先保存本月生活费与初始消费额度，点右上「添加消费卡片」弹窗记账（含备注）；四张大数字卡 + 收支折线图一目了然。

3. 首页黑框内「月额度生活费收支系统」实时显示收支折线（生活费余额 / 消费额度），打开即知本月收支。

4. 「课程表」点击空白格新建、点击已设课程编辑：名称 / 颜色 / 星期 / 节次 / 教师 / 地点 / 总课次 / 已完成 / 备注，弹窗带弹簧 + 动态模糊动画。

5. 在「英语学习」每个节点右侧「打卡」按钮可标记今日完成打钩，顶部显示今日英语打卡进度。

6. 在「数据与曲线」保存数据点绘制曲线；末端「实时」点随录入即时变化。

7. 消费不平衡会自动标红并自动设为最关心项目；也可手动标红。

8. 仪表盘「每日打卡 · 守夜日志」：连续守夜天数 + 本月热力日历 + FNAF 像素时钟；本地时间 ≥ 6:00 打卡触发像素烟花 + 8-bit 胜利音效。

9. 音乐播放器为 aura-music（v1.9.0 本尊）：点右下角悬浮球或顶栏「🎵 音乐」打开；面板可全屏 / 浮窗 / 关闭，不中断播放。

10. 在「前端设置 · 音乐播放器」切换来源：在线本尊 / 本地构建 / 自定义 URL。音乐文件请在面板内用它的“本地导入 / 搜索”添加。

11. 背景「取色氛围流动」会读取你自定义图片主色，生成柔和缓慢流动的氛围光。

12. 所有卡片带「鼠标聚光灯」跟随效果；已深度适配手机。

13. 点击顶部「保存」。若运行了 save-server.js，会写入同级 save 文件夹；若选择了导出文件夹，也会同步写入。

14. 「数据管理」支持导出 / 导入 JSON，并可📁选择导出文件夹（Chrome/Edge，需 http/https）。
